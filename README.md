# Лакония Клин — клининг в Уфе

Адаптивный одностраничный сайт на HTML/CSS/JavaScript, без сборки и платных библиотек.

## Текущие функции
- Услуги и предварительный калькулятор.
- Форма скачивает текстовый черновик заявки на устройство клиента.
- Telegram, MAX, телефон и почта помечены как неподключённые, пока реальные контакты не добавлены.

## Важно
Заявки НЕ отправляются владельцу автоматически. Калькулятор содержит демонстрационные цены. Перед рекламой подтвердите прайс, условия работы, часы и районы выезда, добавьте реальные контакты и подключите канал приёма заявок. Не размещайте токен Telegram в публичном HTML.

## GitHub Pages с iPhone
1. В репозитории откройте **Add file → Upload files** и загрузите этот README (index.html уже добавлен).
2. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
5. Дождитесь публикации и откройте адрес, который GitHub покажет в Settings → Pages. Обычно он выглядит как `https://akramovdaulet-dotcom.github.io/lakoniya-clean/`, но считайте его действующим только после проверки в GitHub и открытия сайта.
