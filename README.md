# Лакония Клин — клининг в Уфе

Адаптивный одностраничный сайт на HTML/CSS/JavaScript, без сборки и платных библиотек.

## Текущие функции
- Услуги и предварительный калькулятор (ставки берутся с сервера, `GET /api/pricing`).
- Форма заявки отправляет её на сервер (`POST /api/public-requests`), оттуда она сохраняется в базе и приходит владельцу в Telegram-бота. На сайте показывается номер заявки.
- Защита от спама: скрытое поле-приманка, лимит заявок с одного адреса и общий лимит, защита от дублей при повторной отправке.
- Контакты под формой (телефон, Telegram, почта) появятся, когда заполнить `CONTACTS` в `index.html`.

## Важно
Калькулятор содержит демонстрационные цены: ставки задаются на сервере (`SERVICE_RATES` в `backend/app.py`). Перед рекламой подтвердите прайс, условия работы, часы и районы выезда, добавьте реальные контакты и политику обработки персональных данных. Не размещайте токен Telegram в публичном HTML. Бэкенд и боты описаны в `backend/README.md`.

## GitHub Pages с iPhone
1. В репозитории откройте **Add file → Upload files** и загрузите этот README (index.html уже добавлен).
2. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
5. Дождитесь публикации и откройте адрес, который GitHub покажет в Settings → Pages. Обычно он выглядит как `https://akramovdaulet-dotcom.github.io/lakoniya-clean/`, но считайте его действующим только после проверки в GitHub и открытия сайта.
