# Поиск потенциальных клиентов для «Лакония Клин» (Уфа)

Агент ищет через Firecrawl Search API публично индексируемые страницы и формирует JSON-отчёт с тремя раздельными списками: **«Подтверждённый кандидат»**, **«Требует проверки»** и **«Отклонён»**. Поиск по домену не означает, что сама площадка доступна или что её страницы удалось проверить напрямую.

## Запуск

Требуется Python 3.11+; для запуска агент использует стандартную библиотеку Python.

```bash
cd backend
python -m lead_finder.agent --limit 5
```

Из папки `backend` отчёт сохраняется в `lead-finder-results.json`, история просмотренных URL — в `.lead-finder-seen.json`. Эти файлы локальные и не должны коммититься.

Firecrawl Search API: https://docs.firecrawl.dev/features/search. Для более стабильных лимитов задайте `FIRECRAWL_API_KEY` в переменных окружения или GitHub Actions Secrets. Не помещайте ключ в код.

## Отчёт и критерии

JSON содержит время генерации, сводку по попыткам поиска и доступности источников, число результатов и дублей, причины отклонения, а также три списка кандидатов. Карточка содержит заголовок, источник, ссылку, дату (или «Не указано»), фрагмент, тип услуги, район, оценку, причину и статус.

- Подтверждёнными становятся только явные запросы на уборку с указанием Уфы, оценкой от 80 и доступной датой публикации в пределах 90 дней.
- Если дата отсутствует, кандидат не подтверждается и остаётся на ручную проверку.
- Отзывы, реклама, каталоги, подборки, вакансии и услуги вне профиля клининга отклоняются.
- Счётчик «успешно доступных источников» означает, что поисковые запросы по соответствующему источнику вернули результат API без ошибки. Это **не** подтверждает прямой доступ ко всем страницам сайта.
- Поисковые сниппеты не всегда содержат полный текст или дату. Проверяйте первоисточник вручную до любых действий.

## GitHub Actions

Workflow **Find Ufa cleaning leads** запускает регрессионные тесты, затем поиск и загружает JSON как артефакт. Его можно запускать вручную с лимитом 3, 5 или 8 результатов на запрос. До слияния PR workflow может быть недоступен для ручного запуска из интерфейса Actions.

## Telegram владельца

При необходимости задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем запустите:

```bash
python -m lead_finder.agent --limit 5 --telegram
```

Сводка отправляется только при наличии подтверждённых кандидатов и только в заданный чат владельца. Агент не пишет клиентам, не публикует комментарии и не собирает личные телефоны.

## Ограничения и безопасность

Агент использует только результаты публичного веб-поиска. Он не обходит логины, CAPTCHA, HTTP 403 или другие ограничения доступа, не обращается к закрытым группам и не использует неофициальные API. Недоступность источника фиксируется в сводке, а поиск продолжается по остальным запросам. Нулевое число подтверждённых кандидатов допустимо и предпочтительнее ложных заявок.
